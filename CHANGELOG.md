# Changelog

## 0.1.0 — 2026-10-10

- Initial daemon with structured journal SSH/fail2ban/kernel events.
- Bounded SSH aggregation, ntfy queue, retries, rate limits and deduplication.
- Persistent boot, outage, hysteresis, hardware, services and maintenance state.
- CLI, least-privilege systemd deployment, offline tests, Ruff and GitHub Actions.
